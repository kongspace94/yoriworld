# 서버 상태 · 노크 Worker 켜는 법

홈페이지는 그림 파일만 있어서 숫자를 저장할 수 없어요. 이 Worker가 대신
① 마인크래프트 서버가 켜져 있는지 확인하고 ② 노크 수를 저장해요. 무료 요금제로 충분해요.

## 1. Cloudflare 계정 만들기
https://dash.cloudflare.com 에서 가입 (카드 등록 필요 없음)

## 2. 저장소(KV) 만들기
대시보드 → 저장소 및 데이터베이스 → KV → 만들기 → 이름 `yoriworld-knocks`

## 3. Worker 만들기
1. 대시보드 → Workers 및 Pages → 만들기 → "Hello World" 로 시작 → 이름 `yoriworld-status`
2. 코드 편집 → 안의 내용을 모두 지우고 `worker.js` 내용을 붙여넣기 → 배포
3. 설정 → 바인딩 → KV 네임스페이스 추가: 변수 이름 `KNOCKS`, 2번에서 만든 저장소 선택
4. 설정 → 변수 및 비밀:
   | 이름 | 종류 | 값 |
   |---|---|---|
   | `MC_HOST` | 비밀 | 마인크래프트 서버 주소 (포트 빼고) |
   | `MC_PORT` | 텍스트 | 포트 (보통 25565, playit이면 그 포트) |
   | `ADMIN_KEY` | 비밀 | 노크 기록 볼 때 쓸 비밀번호 |
   | `ALLOWED_ORIGIN` | 텍스트 | 홈페이지 주소 (예: `https://아이디.github.io`) |
   | `DISCORD_WEBHOOK` | 비밀 | (선택) 노크마다 디스코드 알림 받을 웹후크 주소 |
5. 배포된 주소 확인 (예: `https://yoriworld-status.아이디.workers.dev`)

## 4. 홈페이지에 연결
`웹사이트/status.js` 맨 위 `API` 에 5번 주소를 넣어요.

## 노크 기록 보기
`https://yoriworld-status.아이디.workers.dev/admin?key=비밀번호`
→ 최근 30일 날짜별 노크 수 (같은 사람은 하루 1번만 셈)

## 알아 둘 것
- 서버 주소는 Worker 안에만 있고 홈페이지에는 안 나가요.
- 상태는 30초마다 한 번만 실제로 확인해요 (방문자가 많아도 서버에 부담 없음).
- 노크한 사람의 IP는 그대로 저장하지 않고 알아볼 수 없는 값으로 바꿔서 2일 뒤 자동 삭제돼요.

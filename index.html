지금은 서버가 쉬고 있어요

설치 방법

  1. 받은 압축 파일을 우클릭 → 모두 압축 풀기 (압축을 풀지 않고 실행하면 안 돼요)
  2. 마인크래프트 게임과 런처를 모두 끄기
  3. 풀린 폴더에서 설치하기.bat 더블클릭
    파란 "Windows의 PC 보호" 창이 뜨면 → 추가 정보 → 실행 · 서버 주소를 물어보면 서버 주인에게 받은 주소 입력
  4. 런처를 켜고 플레이 버튼 왼쪽 프로필에서 요리월드 선택 → 플레이 → 멀티플레이 → 요리월드 접속

업데이트가 나오면 새로 받아서 설치하기.bat을 한 번 더 실행하면 돼요. 요리월드 전용 폴더를 따로 써서 원래 마인크래프트나 다른 모드와 섞이지 않아요.
